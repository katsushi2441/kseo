# Kurage SEO（PHP版）

日本語サイトの技術SEOを、**1ファイルのPHP**で診断します。
データベース・Composer・npm は不要。レンタルサーバーにFTPで置くだけです。

## 特徴

- **タイトルの長さを全角で数える。** 英語圏のツールは半角60文字で判定するので、
  日本語サイトは実際には切れているのに「問題なし」と出ます。
- **判定にAIを使わない。** すべて閾値との比較なので、同じページなら何度測っても
  同じ結果になります。「直したのに点が下がった」が起きません。
- **10カテゴリ**をチェックし、指摘ごとに「実測値」と「どう直すか」を出します。
- **診断書（Markdown）**をダウンロードして、そのままお客様に渡せます。

## 見るもの

クロール・インデックス / タイトル・説明文 / 見出し構造 / 構造化データ /
SNS表示(OGP) / コンテンツ / モバイル対応 / 表示速度 / HTTPS・安全性 /
日本語サイト固有

## 設置

[INSTALL.md](INSTALL.md) を読んでください。要点だけ:

1. `kseo.php` と `kseo_data/` をFTPでアップロード
2. `kseo_config.php.example` を `kseo_config.php` にコピー
3. **社外から見える場所ならパスワードを設定する**
4. `https://あなたのドメイン/kseo.php` を開く

## 動作確認

```bash
php scripts/check_kseo.php
```
