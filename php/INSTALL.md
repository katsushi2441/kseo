# Kurage SEO（PHP版）導入手順

PHPが動くレンタルサーバーにアップロードするだけで動きます。
**データベース・Composer・npm は不要**です。

---

## 1. 必要なもの

| | |
|---|---|
| サーバー | **PHP 8.0 以上**が動くレンタルサーバー（共有サーバーで可） |
| 拡張 | 標準構成で動きます（`curl` があれば使い、無ければ `file_get_contents` に落ちます） |
| 外向き通信 | 診断する相手サイトへ出られること |
| データベース | **不要** |

## 2. アップロード

FTPで次の3つを置きます。

```
kseo.php
kseo_config.php     ← kseo_config.php.example をコピーして名前を変える
kseo_data/          ← 中の .htaccess も一緒に
```

`kseo_data/` は診断結果のJSONが入る場所です。同梱の `.htaccess` が
ブラウザからの直接アクセスを塞ぎます。**これを消さないでください。**

## 3. パスワードを掛ける

社外から見える場所に置くなら、**必ず鍵を掛けてください。**
鍵なしのまま公開すると、誰でもあなたのサーバーから他人のサイトへ
アクセスを飛ばせる状態になります。

```bash
php scripts/make_password_hash.php 'あなたのパスワード'
```

出てきた文字列を `kseo_config.php` に貼ります。

```php
define('KSEO_PASSWORD_HASH', '$2y$10$....');
```

サーバーにSSHが無い場合は、手元のPCで上のコマンドを実行しても構いません
（ハッシュは環境に依存しません）。

## 4. 開く

```
https://あなたのドメイン/kseo.php
```

URLを入れて「診断する」を押すだけです。

---

## 使い方のコツ

**ページ数は最初5で十分です。** トップだけを見ても、robots.txt・sitemap.xml・
重複タイトルのような「サイト全体の問題」は複数ページを見ないと出てきません。

**診断書はそのままお客様に渡せます。** 指摘ごとに「実測値」と「対応」が
並んでいて、重大度の順です。上から順に潰せば終わる形にしてあります。

**直したら、もう一度測ってください。** 判定は決定論的なので、直した分だけ
点が動きます。AIが採点しているわけではないので、同じページなら何度測っても
同じ結果になります。

---

## つまずきやすいところ

**「内部ネットワークのアドレスに解決されるURLは監査できません」と出る**

意図した動作です。利用者が任意のURLを投げられる作りなので、
名前解決した先がプライベートアドレスなら拒否します（SSRF対策）。
社内サイトを診断したい場合だけ、設定で外せます。

```php
define('KSEO_ALLOW_PRIVATE', true);
```

**★これを true にした状態で、外部から見える場所に置かないでください。**
社内のサーバーを読むための踏み台にされます。社内LAN内だけで使ってください。

**診断が途中で止まる**

共有サーバーの実行時間制限に当たっています。ページ数を減らすか、
`KSEO_CRAWL_DELAY` を短くしてください（ただし相手サイトへの負荷になります）。

**遅い**

`KSEO_CRAWL_DELAY`（既定1秒）× ページ数です。相手サーバーへ連続アクセス
しないための待ちです。他社サイトを診断する業務で使うなら、
**1.0秒以上を維持してください。**

**文字数の数え方が他のツールと違う**

意図してそうしています。英語圏のツールはタイトルを半角60文字で判定しますが、
日本語を同じ物差しで測ると、実際には検索結果で切れているのに「問題なし」と
出ます。本製品は**全角を1文字、半角を0.5文字**として数えます。

## 判定を自社向けに変える

`kseo.php` の上部に閾値がまとまっています。

```php
const KSEO_TITLE_MAX = 32;      // 全角。日本語の実務値
const KSEO_DESC_MAX = 120;
const KSEO_THIN_CONTENT = 300;
const KSEO_SLOW_SEC = 1.5;
```

判定を足したいときは `kseo_check_page()` に1ブロック書き足すだけです。
**変えたら必ず自己テストを通してください。**

```bash
php scripts/check_kseo.php
```

誤検知は製品として致命的なので、実際に踏んだ誤検知をテストに残す運用に
してあります（`http-equiv` 形式のcharset、英語ページの言語切替リンク、
`/index.html` から `/` へのcanonical の3件が入っています）。

## Python版との関係

同じ判定をPythonで実装した版を、ソース公開しています。

https://github.com/katsushi2441/kseo

**規則ID・カテゴリ名・閾値・採点式をすべて揃えてあり、同じURLにかけると
同じ点数が出ます**（実サイト4件で総合点・カテゴリ別・検出規則まで一致を
確認済み）。常時稼働のサービスとして動かしたい場合はそちらを使ってください。

このPHP版は「レンタルサーバーに置いてすぐ使う」ことに寄せた版です。
